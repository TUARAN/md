# AI 分发大师插件

这是本仓库 `syncblog.2aran.com` 站点的浏览器执行端，在同一个安装包中保留网站现有的 Syncblog 草稿引擎。参考本地 X 高频互动助手、掘金互动助手和小红书插件的按站点工作模式。

## 安装

直接在主站插件下载页输入人员码或站长总密钥，领取已经打包并内置凭证的安装包。Chrome / Edge 116+ 打开扩展管理页，开启开发者模式，加载解压后含 manifest.json 的目录。安装后自动读取凭证并接入监控，首次心跳绑定人员码；不需要自行打包或手动粘贴密钥。已有安装请更新原目录并重新加载，避免同时启用两份插件。

开发与发行由代理运行主站的自动发行脚本完成。构建目录为 `apps/distribution-extension/dist/syncblog-plugin`，基础 ZIP 写入 `output/distribution-extension/` 并自动上传私有 R2，不进入公开网站目录。

“观点”默认读取 2aran.com 首页 RSS 精选的 AI HOT 与阮一峰资讯，可筛选来源、刷新并点击标题带入标题、摘要和来源链接；替换已有内容前会提示确认。

2.0.2：X / 知乎使用浏览器原生输入并回读正文；掘金使用沸点写作入口与新版编辑器选择器；小红书默认文字创作入口。页面无需等待所有资源加载完毕，最多等待编辑器 30 秒；已有内容或部分写入不自动重复填充。浏览器无法访问的网站需恢复访问后再重试。

点击浏览器工具栏图标，或 2aran 主站 / 后台右下角的「AI 分发大师」，打开工作台：

1. 选择观点、文章、电子书或项目，写入内容，也可采集当前网页选中的文字。
2. 可选：在设置中填写自己的 HTTPS Chat Completions 服务地址、模型名和 Key；同意该域名权限后保存。生成仅在点击时发送材料，预览后采用。
3. 保存本地草稿，选择平台；在空白编辑器「填入当前页面」，或按平台逐一准备草稿。
4. 在记录中查看每个平台结果，打开平台核对后自行发布。

电子书 / 项目分发的是「介绍＋链接」，不上传 PDF / EPUB、不创建原生付费小册、不推送代码。小红书图文仍需手动准备图片 / 封面。填充遇到已有文字时停止，避免覆盖。插件不会点击最终发布按钮。「已准备」仅代表当前页面填写并回读成功，不代表云端已保存或已发布。

## 支持范围

首版工作台注册 X、掘金、小红书、知乎、微博、微信公众号、CSDN、思否、博客园、腾讯云、阿里云、华为云共 12 个平台。观点只在具备短内容入口的平台启用。

| 内容入口                                                   | 本版执行方式                                           |
| ---------------------------------------------------------- | ------------------------------------------------------ |
| X 发帖、掘金沸点、知乎想法、微博                           | 检查空白后填写并回读；未识别编辑器时手动完成           |
| 小红书图文                                                 | 填写空白标题与纯文字正文；图片、封面和排版手动处理     |
| 掘金、CSDN、思否、博客园 Markdown 入口                     | 检查空白后填写标题和 Markdown 并回读；未识别时手动完成 |
| X 长文、公众号、知乎长文、微博长文、腾讯云、阿里云、华为云 | 提供入口和复制正文，暂不自动写入未验证的编辑器         |

网站仍可通过原有 `$cose` 协议使用原引擎平台。旧引擎的部分适配会替换编辑器正文，新工作台不直接调用这些未经空白检查的写入操作；站点原有流程保持兼容。

各平台页面和账号权限会变化，自动填写依赖实际打开的编辑器。未找到编辑器、登录跳转、未确认写入均给出需手动检查状态；不会把打开页面当成成功。中断的批次不自动重发，重试前先检查是否已经生成草稿。

## 维护

- 新插件源码：本目录 `master/` 与 `panel.html`。
- 原引擎产物：`apps/web/vendor/syncblog-plugin`；请勿直接修改压缩文件。
- 打包器：`scripts/package-syncblog-plugin.mjs`，构建时添加新域名桥接和严格匹配的消息适配；上游格式改变时构建失败，需审查适配。
- 设计：`docs/designs/ai-distribution-master-plugin.md`。
- 验证：`pnpm test:distribution-plugin`。

密钥、本地草稿和记录只保存在浏览器扩展本地（不是网站账号同步数据）；清理扩展数据或卸载会丢失。记录保留最近 10 批，本地草稿保留最近 20 篇。自配模型费用由所用服务商结算，不与站点账号余额共用。

## 验收边界

自动测试与构建检查不替代真实平台登录后的验收。上线前应分别检查各平台的编辑器、段落、标题、链接、图片、草稿保存状态，以及站点 `$cose` 账号探测和任务回调。请勿使用自己的真实账号做无人值守发布测试。

## 本地版本更新

侧栏显示已加载版本，支持检测更新和点击更新。每 2 分钟检查安装目录中的 manifest.json，新版本持续出现 1 分钟后在空闲时自动加载；分发进行中先排队，结束后更新。未保存的编辑内容会在重新打开侧栏时恢复，平台页面不会自动刷新，以保留已有正文。该机制加载当前安装目录中已打包的新版，不会从网站下载或替换插件文件。首次升级至 2.0.3 需要在扩展管理页重新加载一次。

## 分发标签组

每次分发使用一个独立标签组，名称为「AI 分发 · 内容类型 · 标题 · 时间（北京时间）」；标题为空时取正文开头。观点用橙色、文章用蓝色、电子书用紫色、项目用绿色。手动处理的平台也在同组，重试及记录中的「打开平台」沿用原组；原组已关闭时重新创建，不刷新已填写的页面。

## 2.1.0 平台工具融合

当前网站右侧「平台工具」可打开掘金签到与小红书笔记管理，主导航仍为创作、草稿、记录、设置。掘金自动签到默认关闭，仅开启后且当前活动网站是掘金时执行。平台任务记录可在工具页及「记录 → 平台任务记录」查看。

小红书复用主站 `tools/xhs-interaction-extension/manager-core.js` 与 `manager.js` 的可见范围管理规则（2026-11-02），集成为独立命名的按需页面工具。先扫描预览，用户确认后调整，不删除笔记；每次执行前检查卡片数据，每次设置后重新读取权限。请先停用旧小红书插件并刷新笔记管理页，避免重复任务。定时发文与推荐互动暂未迁入，不自动迁移旧插件密钥或启用状态。

## 文档中心（2.1.2）

标题区「文档中心」打开随插件打包的离线手册；分发、模型设置、更新、签到与笔记管理旁的说明入口直达对应章节。分类目录、可折叠章节、状态表和异常排查采用与 X 高频互动助手文档中心相同的组织方式。

文档唯一内容源位于主站仓库 `lib/content/syncblogDocs.mjs`，网站路由为 `/tools/syncblog-publisher/docs`。主站执行 `node scripts/build-syncblog-docs.mjs <输出目录>` 生成 `docs.html`、`master/docs.css` 和 `master/docs.js`；同步这三个产物后再打包插件。不要直接编辑生成的文档正文，避免线上和离线说明漂移。

## 2.1.3 站点入口

识别主站、后台与已登记的 2aran 子站，并与分发平台身份区分。右下角入口只在 HTTPS 的 2aran.com、www.2aran.com 和 admin.2aran.com 显示。其他平台只执行功能，不自动展开侧栏；可从浏览器工具栏打开工作台控制平台工具。升级时移除已打开平台页遗留的旧浮动入口，不刷新编辑器。

## 2.2.0 后台监控

「设置 → 后台监控」填写站长回执密钥，明确勾选开启后上报。独立设备编号与 X 插件分离，批次只上传编号、类型、目标平台与状态；正文、标题、草稿、URL、Cookie 与模型密钥不上报。后台可停止批次、停止全部任务、关闭自动签到及加载本地新版，不提供发布或启动清理。每分钟和本地状态变化后同步，指令有 2 分钟有效期，领取前持久化，完成后回执。更新指令只在重新加载目标版本后确认成功。

服务端需上线 `/api/plugins/report` 和 `/api/admin/plugins/monitor` 并执行主站迁移 `0129_plugin_monitor.sql`。未上线或未配置时显示失败状态，不影响本地分发。

## 2.2.1 自动交付

安装包自动打到 `output/distribution-extension/`，ZIP 根目录包含 manifest.json；不再放入公开站点目录。主站 `scripts/release-syncblog-extension.mjs` 自动打包、校验并上传私有 R2，后台直接下载，站长不需要选文件上传。站长总密钥或人员码在领取时注入 `community-secret.local`；首次安装自动读取并接入监控，首次心跳绑定设备。手动关闭同步后保持关闭。
