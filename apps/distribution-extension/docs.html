01快速开始安装插件，打开工作台，先完成一份草稿
  1. 在插件介绍页输入人员码或站长总密钥，领取已打包且内置凭证的 VIP 安装包，解压后在 Chrome / Edge 扩展管理页开启开发者模式，加载含 manifest.json 的目录。支持 Chrome / Edge 116 及以上。
  2. 登录目标平台，点击浏览器工具栏的矿工图标打开侧栏；2aran 主站和站长后台右下角也提供「AI 分发大师」入口。第三方平台只执行功能，不显示浮动按钮，也不自动展开面板。先确认「当前网站」识别结果。
  3. 在「创作」中选择内容类型，填写正文，可保存本地草稿。直接填写和复制不需要配置模型。
  4. 需要 AI 改写时，到「设置」填写模型服务地址、模型名与 API Key，授权后保存。生成内容先预览，再采用。
  5. 首次只选择一个平台准备草稿，到「记录」打开平台核对标题、正文、链接与保存情况，确认后自行发布。
02界面与入口四个主导航保持创作流程，低频操作进入平台工具
入口可以做什么
创作编辑观点、文章、电子书或项目介绍；从 RSS 取材，预览 AI 适配，准备平台草稿。
草稿查看、载入和删除本机草稿；删除前会确认。
记录查看每个平台的分发结果；展开「平台任务记录」可查看签到与笔记管理结果。
设置配置兼容 Chat Completions 的 HTTPS 模型服务、模型名称与密钥。
平台工具位于「当前网站」旁；可进入掘金签到和小红书笔记管理，当前网站的工具排在前面。
右下角入口仅 2aran.com、www.2aran.com 和 admin.2aran.com 显示；其他网站可通过浏览器工具栏打开侧栏，平台任务继续由工作台控制。
文档中心标题区域常驻入口；功能旁的「说明」直达对应章节，在独立标签页查看，不离开正在编辑的内容。
03内容类型与平台能力四类内容共用草稿、AI 适配与分发记录

观点适合短内容；文章填写标题与 Markdown 正文；电子书与项目填写介绍及访问链接。电子书分发介绍帖，不上传 PDF / EPUB，也不创建平台付费小册；项目分发介绍与链接，不推送代码。

平台入口执行方式
X、掘金沸点、知乎想法、微博检查空白编辑器后填写正文并回读。
小红书填写空白标题和纯文字正文；图片、封面及排版由你处理。
掘金、CSDN、思否、博客园 Markdown 入口填写空白标题与 Markdown；无法识别时转为手动检查。
公众号、X 长文、知乎长文及云社区等提供入口和正文复制，具体能力以当前工作台提示为准。
04草稿、记录与标签组准备内容后到目标平台检查，插件不会点击最终发布

「填入当前网站」只处理当前平台；「准备所选平台草稿」逐个平台处理。已有正文或标题时停止写入，避免覆盖。部分写入或回读失败后，不会自动重复填充。

每批分发建立一个独立标签组，名称含内容类型、标题和北京时间。观点为橙色、文章为蓝色、电子书为紫色、项目为绿色；记录中的「打开平台」和重试会沿用该批标签组。

「已准备」只代表页面填写并回读成功。请在平台检查保存状态，必要时刷新确认，再自行发布。重试失败项前，先检查原页面是否已经留下正文或草稿。

草稿保留最近 20 篇，分发记录保留最近 10 批。插件重启后，未完成的分发项显示「已中断」，不会自动重发。

05AI 设置与 RSS 取材模型配置共用，生成内容先预览再采用

模型服务须为完整 HTTPS Chat Completions 接口地址，不带账号、密码、查询参数或片段。填写模型名称和自己的 API Key；保存时按提示授权该服务域名。

点击生成时，当前材料和改写要求会发送到所配置的模型服务。费用由该服务计费。生成结果先显示在预览框，只有点击「采用为当前正文」才替换正文。

观点入口提供 2aran.com 首页 RSS 精选，可按来源筛选、刷新并点击标题带入内容；编辑器已有内容时会先询问是否替换。资讯需自行核对后再发布。

06掘金每日签到可手动签到；自动签到默认关闭
  1. 点击「平台工具 → 掘金 · 每日签到 → 立即签到」，插件打开签到页，使用当前浏览器的登录状态。
  2. 成功标记依赖页面出现「已签到」「签到成功」或「今日已签」等确认文本。只点击按钮或按钮消失，都不计为成功。
  3. 需要自动签到时，单独勾选「自动签到」。开启后每 15 分钟检查一次，仅在当前活动网站为掘金时执行；北京时间每天成功一次。
  4. 取消勾选可关闭自动签到。网络、登录或页面识别失败时，先检查签到页，再手动重试。结果在平台任务记录查看。

已有分发或笔记管理任务执行时，签到会提示等待。旧掘金插件的启用状态不会自动迁移；不要同时开启两份签到任务。

07小红书笔记管理与清理先预览候选，确认后调整可见范围，不删除笔记
  1. 先停用旧小红书插件，刷新笔记管理页，避免两个工具同时修改笔记。
  2. 点击「平台工具 → 小红书 · 笔记管理 → 打开笔记管理 / 清理」。工具在小红书创作平台笔记管理页显示。
  3. 选择最近 7 天、最近 1 个月、最近 3 个月或全部笔记，查看当前已加载卡片的候选及预计可见范围。
  4. 检查规则和候选后点击「开始设置」，确认提示后才执行。执行时按批处理并滚动加载后续笔记；初始预览不代表已加载全部笔记。
  5. 需要中断时点击「停止」或「收起」，工具会停止后续处理；已经完成的权限调整会保留。结果可在平台任务记录查看。

每篇执行前重新读取点赞、评论、发布时间及目标权限；数据变化或按钮结构异常时跳过或停止。保存后重新打开权限弹窗核对结果，不能确认就报错。插件不会删除笔记。

定时发文和推荐互动暂未迁入 AI 分发大师，仍由旧插件管理；融合版不会自动启用旧任务或导入旧密钥。

条件（按顺序判断）目标可见范围
评论超过 10 条公开可见。即使原来是私密，也可能被设为公开，执行前务必核对。
不满足上一条，且点赞少于 100，赞评数均可读取仅自己可见。
其余、统计数无法判定或时间范围内日期无法读取跳过，不推测数值。
08后台监控与远程控制明确开启后，同步设备、批次、工具与版本，不上传正文
  1. 确认主站和后台已上线监控接口并完成数据表部署。进入插件「设置 → 后台监控」，从下载页领取的安装包已内置凭证，首次安装会自动读取并接入监控；本地开发包才需要手动填写回执密钥。
  2. 勾选「开启后台同步与远程停止 / 更新」并保存。默认关闭；插件使用独立设备编号，不与旧 X 插件共享实例身份。
  3. 进入站长后台「插件监控 → AI 分发大师」，按设备、日期和目标平台查看批次进度与结果。首次心跳后设备才会出现。
  4. 可下发停止批次、停止全部、关闭自动签到或加载本地新版。停止批次会完成当前步骤后停止后续平台；停止全部同时关闭自动签到并通知笔记管理停止。
  5. 指令显示待领取、执行中、确认完成、失败或过期。心跳约每分钟及状态变化后上报；后台每 10 秒刷新视图。设备离线时不提供远程操作，指令有效期为 2 分钟。

后台只接收批次编号、内容类型、目标平台、结果状态、签到和工具状态、版本与心跳。不会收到标题、正文、草稿、页面 URL、Cookie 或模型密钥。

已准备数量表示填写并回读成功，不代表保存或发布成功。监控仅统计已上报的结果，本地未开启同步期间的历史可能不完整。

更新命令只加载本机安装目录中的新版，只有重新加载目标版本后才确认完成。后台不提供直接发布或启动笔记清理。接口尚未部署、密钥无效或网络异常时，设置里显示上报失败，本地分发仍可使用。

09状态与异常恢复区分已填写、需手动完成、失败和中断
状态或问题下一步
已准备 · 待检查打开平台核对内容和保存状态，确认后自行发布。
需手动完成检查平台提示。部分平台只提供手动入口，可复制正文后填写。
准备失败 / 已中断先查看原页面有无内容，再决定是否重试这一项，避免重复草稿。
已有内容，停止写入保留原内容，手动核对；如需使用新内容，先自行处理原稿。
找不到编辑器 / 页面无法打开先解决网络或登录问题，打开正确编辑入口；平台结构变化时手动完成。
浏览器错误页 / 加载超时表示尚未成功进入编辑器；先检查对应标签页的网络、登录或验证提示。历史结果保留原状态，重试后才更新检测时间和版本。
模型请求失败核对完整接口地址、模型名、密钥、访问授权与服务余额。
小红书提示旧插件冲突停用旧小红书插件并刷新笔记管理页，再从平台工具打开。
权限无法确认查看当前笔记与权限弹窗，核对已经完成的结果后再操作。
10本地更新与按钮检测安装目录中的新版，空闲时加载

每 2 分钟检查本地目录；检测到的新版持续存在至少 1 分钟，且没有任务执行时自动加载。这个机制不会从网站下载 ZIP，也不会替换安装目录的文件。

更新前保留未保存的编辑内容，重新打开侧栏后恢复。平台页面不会因插件更新而自动刷新，以免丢失已经填写的正文。

按钮或状态含义
检测更新读取当前本地安装目录中的 manifest.json，比较版本。
立即更新有新版时申请加载；任务执行中会排队等待。
新版空闲后自动更新定期检测到新版本，稳定后等待空闲加载。
等待更新分发、AI 生成、签到或笔记管理尚在执行，结束后再加载。
当前目录已是最新版已加载版本与本地目录一致；不代表已检查网上的安装包。
11本机数据与版本记录草稿、密钥、记录分别保存在扩展本地

草稿、模型密钥、分发记录、平台工具设置和最近 30 条平台任务记录保存在当前浏览器扩展本地。不同浏览器配置文件互不共享；卸载扩展或清理扩展数据会丢失，重要内容请另行保存。

同一份文档同时用于网站和随插件提供的离线文档。文档版本与插件版本显示在页首，排查时先确认正在使用的版本。
