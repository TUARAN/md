# AI 分发大师插件设计与实施

日期：2026-11-02

## 产品目标

在 syncblog.2aran.com 的现有 Syncblog 草稿引擎之上提供可独立使用的浏览器插件（属于当前仓库，不新建项目）。借鉴本地 X 高频互动助手、小红书和掘金助手的「一个常驻工作台 + 按站点加载能力」模式，但将主要流程聚焦在内容分发。

用户流程：打开任一支持站点 → 点击浮动入口或工具栏 → 识别当前平台 → 编写 / 采集选中文字 → 选择观点、文章、电子书或项目 → AI 适配并检查 → 填入本站或批量准备平台草稿 → 查看分项结果并手动发布。

## 界面

- 顶部：AI 分发大师、当前站点、返回 Syncblog 创作台。
- 创作：四种内容类型；标题、正文、来源链接；本地草稿保存；采集当前选区。
- 分发：随类型变化的平台能力清单；明确显示自动填充、手动入口、不支持；逐个平台准备。
- AI：用户自配兼容 Chat Completions 的服务地址、模型和密钥；生成平台适配版本，预览后采用。没有配置时不伪装生成。
- 草稿与记录：保存在扩展本地，记录每个平台的待处理、运行中、已准备、需手动、失败、中断状态。

## 内容语义

- 观点：短观点正文，进入 X 发帖、掘金沸点、知乎想法、微博等短内容入口。
- 文章：标题和 Markdown 正文。原站点保留长文草稿引擎；新工作台仅执行具备空白检查和内容回读的适配器。
- 电子书：名称、介绍、阅读 / 购买链接，生成介绍帖；不创建平台付费小册，不上传 EPUB / PDF。
- 项目：名称、介绍、演示 / 仓库链接，生成项目介绍帖；不推送仓库或创建平台项目。
- 平台未覆盖的类型明确禁用，不能仅凭「已打开页面」宣称分发成功。

## 技术设计

Manifest V3 / Chrome 116+。工具栏打开原生 Side Panel；支持站点注入 Shadow DOM 浮动入口，不污染页面样式。平台域名精确匹配或子域匹配，路由和编辑器选择器按平台集中配置。

新源码独立放在 `apps/distribution-extension`；原始 `apps/web/vendor/syncblog-plugin` 继续保存上游引擎，不直接编辑压缩代码。打包脚本在临时构建目录合并引擎和新工作台、生成 Manifest，以及可审计的引擎消息适配器。站点继续使用 `$cose`，原下载地址保持可用，新增 AI 分发大师品牌的下载地址。

后台负责串行任务与本地进度写入；批次逐平台执行且防止重复启动。服务进程意外中止后将运行项标为需检查，不自动重复写入。失败项可单独重试；平台页面变更或编辑器未就绪时显示实际错误和手动入口。自动填充不点击发布按钮；有内容的编辑器拒绝覆盖。

密钥只保存在扩展本地，并将 local storage 限制为受信扩展上下文。AI 请求由后台发起，设置时按服务域名单独申请权限；禁止将密钥、正文和任意后台请求暴露给网站消息。只接受扩展界面发起的写入 / AI / 批次命令；网页浮动入口仅可请求打开面板。

## 验证与交付

验证平台路由、四类内容语义、HTML 转义、链接验证、权限与消息来源、串行状态、失败重试、草稿持久化和构建资源完整性。生成可加载的解压目录和 ZIP。浏览器中检查实际面板布局；真实账号平台草稿 / 发布需登录后的人工验收，未实测平台不得宣称已经端到端发布成功。

## 范围

本版不移植 X 助手的自动评论、点赞、关注、定时轰炸，也不包含云端账号托管。后续可独立扩展素材库、逐平台保存不同改写版本、发布后数据回流。

## 主域名与项目收拢

统一入口为 https://syncblog.2aran.com/；当前仓库的两份 Wrangler 配置已包含该域名，统一账号系统也已采用该域名。继续在当前 md 仓库内维护网站和配套插件，旧 syncblog.cn 仅做兼容。插件构建必须同时更新新域名的 host permission、content script、web accessible resource 和页面桥接 hostname 白名单，不能只替换可见链接。

## 审查后的执行边界

旧引擎部分适配会覆盖编辑器，部分成功回执没有正文核验。因此原引擎仅留给网站已有 `$cose` 协议兼容，新工作台不直接调用未校验的旧写入。自动适配覆盖 X 短帖、掘金沸点、知乎想法、微博、小红书文字，以及掘金 / CSDN / 思否 / 博客园 Markdown 入口；其余长文入口显示手动完成。识别到多个正文框或缺少必须的标题框时也停止。小红书为纯文字填写，不声称保留 Markdown 富文本样式。
